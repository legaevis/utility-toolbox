## Utility Toolbox v0.20.0

Первый публичный релиз. Офлайн-набор инструментов для работы с текстом,
списками и данными — всё обрабатывается локально, без аккаунтов, серверов и
аналитики. / First public release. An offline-first toolbox for text, lists
and data — everything is processed locally, no accounts, no servers, no
analytics.

**Что внутри / What's inside**

- Типограф: 100 правил типографики (RU/EN), библиотека из 160 символов, статистика и просмотр изменений / Typograf: 100 typography rules (RU/EN), a 160-symbol library, stats & diff view
- Daily Report: локальные записи за день и отчёт за период / local day notes and period reports
- 30 инструментов: конвертация регистра, раскладка RU↔EN, чистка текста, списки, генераторы, конвертер величин, часовые пояса и др. / 30 tools: case converter, RU↔EN layout fixer, text cleaner, list tools, generators, unit converter, time zones and more
- Светлая и тёмная темы, интерфейс RU/EN / Light & dark themes, RU/EN interface

**macOS — первый запуск.** Приложение не нотаризовано: распакуйте zip,
перенесите Utility Toolbox.app в «Программы», затем нажмите на него
правой кнопкой → «Открыть» → «Открыть» (один раз). / The app is not
notarized: unzip, move to Applications, then right-click → Open → Open
(once).

**Windows — первый запуск.** Установщик не подписан, SmartScreen покажет
предупреждение: нажмите «Подробнее» → «Выполнить в любом случае». / The
installer is unsigned; in the SmartScreen prompt click "More info" →
"Run anyway".

Контрольные суммы — в `SHA256SUMS.txt`. / Checksums are in `SHA256SUMS.txt`.
